# Starting point: single brackets taught but not secure

Expanding brackets has been taught at school, but single brackets like 3(x + 4) still cause mistakes, especially with negatives. So the course starts from the meaning of a single bracket (area model), with positives only, and gives negatives their own lessons.

**Evidence**: stated by the user at the start (2026-11-23); no performance data yet.

**Implications**: don't assume double brackets or negative multipliers are known. Look for evidence from lesson 1 practice (tries vs. 8 correct) before moving on to negatives.
